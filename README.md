# Ясность — лендинг студии лазерной эпиляции (Владивосток)

Одностраничный сайт для студии «Ясность» ([@yasnost_vl](https://www.instagram.com/yasnost_vl/)), ЖК «Море», ул. Мыс Кунгасный, 3Б.

## Структура

```
index.html          — страница (10 блоков)
css/style.css       — стили
js/main.js          — логика (без библиотек)
img/                — оптимизированные изображения (WebP + JPG-фолбэк), иконки, OG-картинка
video/process.mp4   — ролик «процесс → результат» (H.264, без звука, faststart)
robots.txt, sitemap.xml — SEO
llms.txt            — GEO: структурированное описание студии для ИИ-поисковиков
site.webmanifest    — манифест и иконки для iOS/Android
build.py            — генератор прайс-листа в index.html (запускать после правки цен)
```

## Блоки

1. Первый экран: заголовок «проявляется» из размытия при загрузке, кнопка записи в YClients.
2. «Профессиональные люди — профессиональное оборудование» — диптих и принципы безопасности.
3. Путь к гладкой коже — видео процедуры и три шага курса.
4. Страхи и мифы — раскрывающиеся ответы.
5. Калькулятор цен — комплексы, женская и мужская эпиляция; подсказывает, если комплекс выгоднее; запись онлайн в YClients, уточнить набор можно в WhatsApp.
6. Абонементы — билеты с выгодой и кешбэком.
7. Мастера и атмосфера студии.
8. Подарочный сертификат — номинал на выбор или своя сумма, имя, пожелание, формат; живое превью и готовое сообщение в WhatsApp.
9. Отзывы — слайдер (свайп, стрелки, клавиатура, точки).
10. Контакты и Яндекс Карта (загружается лениво).

Плюс бургер-меню на мобильных и плавающая кнопка WhatsApp.

## Перед публикацией

- Замените домен `https://yasnost-vl.ru/` на реальный в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`.
- Фото с 2ГИС содержат водяной знак — желательно заменить на оригиналы от студии (те же имена файлов в `img/`).
- Проверьте, что фото мастеров подписаны верно: `img/maria.*` — Мария Мовчаненко, `img/lolita.*` — Лолита Хмельницкая.
- Цены меняются в `build.py` (зоны) и в `index.html` (комплексы, абонементы), а также в `llms.txt`.

Совместимость: последние версии Chrome, Safari (iOS 13+), Firefox, Edge, Samsung Internet. Учтены `prefers-reduced-motion`, safe-area на iPhone, доступность с клавиатуры.
